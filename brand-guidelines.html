Logo System

Primary Logo Mark

The Equalaw logo mark is the primary icon used for favicons, app icons, and social media profile pictures. It maintains a consistent stroke width of 2.5px and can be rendered in black or white depending on the background.

Logo Mark

Primary icon for favicons and UI elements

Wordmark

Text + mark combination for headers

Aspect Specification Notes
Stroke Width 2.5px Consistent across all variations
Minimum Size 24px × 24px Favicon: 32px, UI elements: 32px+
Clear Space 8px padding Minimum space around logo
Format SVG Scalable vector format only
Colors #000000 or #FFFFFF Depending on background contrast

Logo Variations

Horizontal: Logo mark + wordmark side-by-side (preferred for headers)

Stacked: Logo mark above wordmark (preferred for limited width areas)

Mark Only: Logo mark standalone (favicons, social icons)

Brand Guidelines

✓ Do's

  • Use the logo mark for favicons
  • Maintain consistent stroke width of 2.5px
  • Use approved colors only
  • Maintain minimum clear space
  • Scale logo proportionally
  • Use SVG format for all logos
  • Test on multiple backgrounds

✗ Don'ts

  • Don't distort or stretch the logo
  • Don't change stroke width
  • Don't add effects without approval
  • Don't use raster images instead of SVG
  • Don't place on clashing backgrounds
  • Don't shrink below 24px × 24px
  • Don't rotate or flip the logo
